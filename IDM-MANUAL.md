# Изучение официального мануала IDM (Russian Help, idm_ru.chm)

Источник: `C:\Program Files (x86)\Internet Download Manager\Languages\idm_ru.chm`
(извлечён через `hh.exe -decompile`, декодирован из windows-1251 в UTF-8).
Дополнительно: `idman.chm`, `scheduler.chm`, `grabber.chm`, `tutor.chm`.

## Диалог «Опции» — 9 вкладок (Options.htm)

Мануал прямо указывает: «Диалог имеет девять вкладок»:

1. **Общее** — автозапуск, интеграция в браузеры (базовая/расширенная), отслеживание URL
   в буфере обмена, специальные клавиши захвата, «Обнаруживать новые приложения».
2. **Типы Файлов** — список типов файлов для перехвата; исключённые сайты (`*.site.com`),
   список исключаемых адресов.
3. **Соединение** — скорость соединения, «Макс. количество потоков» (рекомендуется ≤ 4),
   таблица исключений (число соединений для сервера), «Ограничения по загрузке» (квоты).
4. **Сохранение** (Save To) — папки по умолчанию для категорий, «Запомнить последний путь»,
   папка временных файлов.
5. **Загрузка** — диалоги (прогресс/начало/конец), тихий режим, «Запускать загрузку немедленно
   при показе диалога», «При докачке игнорировать смену даты изменения файла», антивирус.
6. **Прокси** — прокси-серверы, «Взять из IE», FTP PASV, авторизация прокси, исключения.
7. **Пароли сайтов** — логины/пароли для URL и каталогов (в мануале: только в зарегистрированной версии).
8. **Dial Up** — соединение Windows, логин/пароль, число попыток и интервал.
9. **Звуки** — звуковые события, файлы Windows/Media, кнопки «Обзор»/«Тест».

## Главное окно (Main.htm)

- Категории: Все загрузки, Скачанные, Документы, Музыка, Программы, Видео, Завершённые,
  Незавершённые, Посещены Граббером, Очереди.
- Добавление: кнопка «Добавить», URL, можно несколько URL; диалог «Информация о загружаемом файле».
- Очереди: создание очередей, запуск/остановка очереди, автоматический запуск следующей.
- Правая кнопка: старт/пауза/возобновить/отмена/удалить/свойства/открыть папку/копировать URL.

## Кастомизация (Customization.htm)

- 4 встроенных варианта панели инструментов: большие/маленькие объемные, большие/маленькие классические.
- Правый клик по тулбару → стиль, размер кнопок, «Выбор...» (порядок кнопок вверх/вниз).
- Правый клик по заголовку столбца → видимость, ширина, порядок (и drag&drop заголовков).

## Прочее

- **Segmentation.htm**: файл делится на части, параллельные соединения, докачка с места обрыва;
  несколько соединений существенно ускоряют загрузку на кабельных/высокоскоростных линиях.
- **Starting.htm**: Ctrl + клик — принудительный перехват; Alt + клик — не перехватывать.
- **Copy_Links_to_Clipboard.htm**: монитор буфера обмена, «Добавить все» для списка URL.
- **Scheduler** (`scheduler.chm`, реестр `Software\DownloadManager\Scheduler`): запуск/остановка
  по времени, квоты, файлы расписания `s_%s.dt` / `q_%s.dt`.

## Применено в SDA

- Диалог настроек полностью покрывает вкладки мануала (9 + вкладки новых версий):
  `Общее / Типы Файлов / Соединение / Сохранение / Загрузка / Прокси / Пароли сайтов / Dial Up / Звуки / Резерв-Сканирование / Интеграции`.
- **Общее**: запуск при входе в Windows (реестр HKCU Run), расширенная интеграция,
  Ctrl/Alt-перехват, обнаружение новых приложений, монитор буфера обмена.
- **Типы Файлов**: редактируемые расширения, исключённые сайты/URL (фильтр при добавлении).
- **Соединение**: потоки, максимум одновременных, лимит скорости, retries, timeouts,
  тип соединения, таблица исключений (потоки на сайт — применяется в движке), квоты.
- **Сохранение**: папка загрузок, папки по категориям, временная папка, запоминание пути.
- **Загрузка**: планировщик, диалоги, тихий режим, антивирус после завершения.
- **Прокси**: URL, логин/пароль (HttpClient::with_proxy_auth), FTP PASV, исключения.
- **Пароли сайтов**: список `URL|логин|пароль|cookie`, автоматическое применение к задаче.
- **Dial Up / Звуки / Резерв**: настройки сохранены; звуки проигрываются через PlaySoundW,
  резервное копирование выполняется после завершения.
- **Очереди**: автозапуск следующей задачи; видимые колонки настраиваются в конфиге.
- Все настройки сохраняются в `%LOCALAPPDATA%\SDA\settings.json` (`#[serde(default)]`).
